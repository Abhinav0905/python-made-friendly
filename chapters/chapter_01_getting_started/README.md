# Getting Started with Python

## Check Your Understanding

1. A compiled language normally translates source code into another executable form before it runs. An interpreted language runs source through an interpreter, so Python supports a short edit-run-check cycle without a separate build step.
2. Dynamic typing keeps code short because a name does not need a declared type and can later refer to another kind of value. The tradeoff is that some type mistakes appear only when the affected line runs.
3. REPL means Read-Eval-Print Loop. It reads one entry, evaluates it, prints an expression's result, then waits for the next entry.
4. An expression produces a value, such as `2 + 2`. A statement performs an action, such as assigning a value to a name, and does not necessarily produce a displayed value.
5. Python source must be plain text so the interpreter receives only source characters. Word processors can add formatting and typographic characters that are not valid Python syntax.

## Try It Yourself

1. Compute `15 * 23`: `q01_multiply_15_by_23()`.
2. Store a name in `me` and greet it: `q02_greet_me()`.
3. Extend `hello.py` with a favorite-color question: `q03_hello_with_color()`.
4. Check whether a Python version is 3.8 or newer: `q04_python_version_is_supported()`.
